# Security Policy

## Supported version

Security fixes target the current `main` branch.

## Reporting a vulnerability

If the repository's **Security** tab offers **Report a vulnerability**, use that form to submit the report privately. Availability depends on the repository setting and is not assumed by this policy.

If that form is unavailable, do not publish exploit details. Open a minimal public issue that contains no sensitive technical information and asks the maintainer to establish a private contact path before you share the report.

Once a private path is available, include the affected file or behavior, reproduction steps, expected impact, and any suggested mitigation. This project is a client-side prototype and must never contain credentials or secrets.
