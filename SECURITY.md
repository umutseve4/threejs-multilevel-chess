# Security Policy

## Supported version

Security fixes target the current `main` branch.

## Reporting a vulnerability

Please use GitHub's **Private vulnerability reporting** feature for this repository. Do not open a public issue for an unpatched vulnerability or include exploit details in a public pull request.

Include the affected file or behavior, reproduction steps, expected impact, and any suggested mitigation. This project is a client-side prototype and must never contain credentials or secrets.
